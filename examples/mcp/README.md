# MCP

| Example | Contents |
| :-- | :-- |
| [mcp.py](mcp.py) | Connect to a remote server, start a local server, start a server in the workspace |

## Setup

Install `mcp` and set the remote server's address and token:

```bash
pip install mcp
export DOCS_MCP_URL=https://mcp.example.com/mcp
export DOCS_MCP_TOKEN=...
```

## Run

```bash
python mcp.py
```
