# Sessions

| Example | Contents |
| :-- | :-- |
| [sessions.py](sessions.py) | Reopen a session, add messages, message queue, rewind, fork |
| [event_stream.py](event_stream.py) | Print all events in a turn, converting events into what the frontend displays |
| [reconnect.py](reconnect.py) | The frontend disconnects mid-answer and resubscribes using `after` and `snapshot` |

## Run

Run from this directory, e.g.:

```bash
python event_stream.py
```
