# Skills

| Example | Contents |
| :-- | :-- |
| [main.py](main.py) | Load skills on demand, run scripts in a skill, pick the skills used for a turn |

The skills are in the [skills](skills) directory.

## Setup

Scripts in skills run in the workspace sandbox, which requires srt; see [Workspace](../workspace/README.md) for how to install it.

## Run

```bash
python main.py
```
