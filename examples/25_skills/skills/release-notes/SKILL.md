# 编写版本说明

1. 把提交分为三类：新功能、修复、其他。
2. 每条改写成面向用户的一句话，不出现内部模块名。
3. 运行 `python3 scripts/next_version.py <当前版本> <是否有新功能:yes/no> <是否有不兼容改动:yes/no>` 得到下一个版本号。当前版本未知时按 1.0.0 处理。
4. 按以下格式输出：

```
## <版本号>

### 新功能
- ……

### 修复
- ……
```
